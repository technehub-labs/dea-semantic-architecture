# Build a Specialized Asset

> **Status:** outline only. Full playbook lands in Phase 4 of [CR-ESA-01](./change-requests/CR-ESA-01.md).

## Outline

1. **Choose the sector** — name it; scope it; identify the design partners.
2. **Derive sector tenets** — start from the three base tenets + ECF axioms; add sector-specific tenets with explicit ECF derivation.
3. **Choose the semantic-layer architecture** — which layers apply; how they are organised.
4. **Author the vocabulary** — sector-specific vocabulary conforming to vocabulary-governance patterns (Phase 4).
5. **Author the concept graph** — concept definitions + concept-graph topology conforming to `technehub-labs/dea-concepts-model` (CR-CM-001).
6. **Author the sector ESA asset** — sector semantic-layer architecture document.
7. **Register** — `registry-entry.yaml` + submit a sector-content CR (e.g. `CR-ESA-02`).
8. **Review** — peer review per `GOVERNANCE.md` (Phase 4).

Phase 4 ships the full prose for all 8 steps with worked examples from the telecom operator sector (Phase 2).
