# Axioms

This directory holds the three ESA axioms in their own files, each with its full derivation table to the ECF 7×7 axiom grid.

The three placeholder axioms (final prose in Phase 1):

1. `axiom-01-semantic-layer-discipline.md` — semantic layers are explicit architectural choices.
2. `axiom-02-vocabulary-governance.md` — vocabulary governance is a first-class discipline.
3. `axiom-03-concept-graph-topology.md` — concept graphs admit multiple edge kinds, not just hierarchies.

Each axiom file ships in Phase 1 with:
- Statement.
- ECF derivation table.
- Operational rule.
- Anti-pattern.
- Cross-references.
